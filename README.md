## 🤖 DEVI — The Continuously Evolving AI Teacher & Operator

TG KindSync Pro features **DEVI**, your unified autonomous AI Teacher, Sentinel Watchdog, and Personal Operator. DEVI lives in an isolated architecture with zero risk to the main Telegram forwarder.

### Quick Launchers:
- **`START_ALL.bat`**: 1-Click launcher running both Master Engine & DEVI AI Teacher.
- **`START_DEVI_ALL.bat`**: Master menu (Console, Sentinel Live HUD, Web Dashboard, Evolution Daemon, Verification).
- **`START_AI_TEACHER.bat`**: Dedicated DEVI Sentinel Watchdog & Live Telemetry HUD.
- **`START_DEVI.bat`**: Interactive natural language CLI.

### Features & Capabilities:
- **Unified Sentinel Watchdog**: Live engine telemetry, log tailing, SQLite WAL inspection, and instant FloodWait alerts.
- **Telegram Saved Messages AI Center**: Full remote control via slash commands (`/status`, `/backup`, `/report`, `/errors`, `/dlq`, `/research`) PLUS natural language chat with DEVI.
- **Multi-Model AI Brain**: Powered by Google Gemini 2.5 Flash, Groq, and OpenRouter with offline local fallback.
- **Self-Evaluation & Evolution**: Tracks skills, benchmarks capability growth, and proposes verified upgrades requiring user approval.
- **Production Asset Shield**: Complete protection barrier for Telegram `.session` files and production databases.
