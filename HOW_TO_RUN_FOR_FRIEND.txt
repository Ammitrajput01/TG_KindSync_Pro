⭐ SABSE AASAAN TARIQA (1-CLICK RUN):
--------------------------------------------------------------------------------
1. Python install hona chahiye (agar nahi hai toh automatically install karega):
   - Link: https://www.python.org/downloads/
   - ⚠️ IMPORTANT: Setup ke waqt "Add python.exe to PATH" tick zaroor karein!

2. Bas "1_START_FORWARDER.bat" par double-click karo!
   - Ye automatically virtual environment aur libraries setup kar lega.
   - Agar pehli baar chala rahe ho, toh screen par aapse API_ID aur API_HASH
     mangega (jo https://my.telegram.org par 1 minute me free milta hai).
   - Ek baar daal doge toh hamesha ke liye `.env` me save ho jayega!

3. Telegram Login Wizard:
   - Screen par visual QR Code ya Phone Number prompt aayega.
   - QR code ko Telegram app se scan kar sakte ho:
     (Telegram App ➔ Settings ➔ Devices ➔ Link Desktop Device)
     YA
   - Apna Mobile Number enter karo (+91...), Telegram par aane wala 5-digit code daalo!

4. Forwarding Shuru Karo:
   - Menu me SOURCE CHAT (jahan se message copy karne hain) aur TARGET CHAT
     (jahan bhejne hain) enter karo.
   - Option 1 (Live Forwarding) ya Option 2 (Range / Batch Copy) chala do!
