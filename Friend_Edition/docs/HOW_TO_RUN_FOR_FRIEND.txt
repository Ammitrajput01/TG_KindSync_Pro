Welcome! This folder contains everything needed to run TG KindSync Pro.
You can run it in TWO WAYS:

------------------------------------------------------------------------------
METHOD 1: RUN LOCALLY ON YOUR OWN PC (RECOMMENDED - 100% LOCAL & PRIVATE)
------------------------------------------------------------------------------
No cloud server, no VPS, and no SSH key required! It runs 100% on your PC.

1. Make sure Python 3.10+ is installed on your Windows PC:
   - Download from: https://www.python.org/downloads/
   - IMPORTANT: Check the box "Add python.exe to PATH" during installation.

2. Simply Double-Click:
   👉 `RUN_LOCALLY_ON_MY_PC.bat`  (or option [1] in `1_START_FRIEND_EDITION.bat`)

3. On first run:
   - It will automatically install all needed libraries (Telethon, Rich, etc.).
   - Enter your phone number (+91...) and OTP to login to your Telegram account.
   - Choose your source and destination channels/topics from the interactive menu.
   - That's it! High-speed cloning begins immediately on your PC.

------------------------------------------------------------------------------
METHOD 2: CONNECT TO ORACLE CLOUD VPS (24/7 REMOTE MODE)
------------------------------------------------------------------------------
Use this if you want the forwarder to run 24/7 on the cloud server even when
your PC is turned OFF.

1. Double-click: `1_START_FRIEND_EDITION.bat`
2. Select Option [2] to connect to the terminal and configure your run.
3. Select Option [3] to launch the 24/7 Autopilot daemon on the server.
